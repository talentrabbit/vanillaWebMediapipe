# Custom digit PNGs

Place optional custom textures here to override generated digit PNGs.

## Naming convention

Use one PNG per digit with these exact filenames:

- `0.png`
- `1.png`
- `2.png`
- `3.png`
- `4.png`
- `5.png`
- `6.png`
- `7.png`
- `8.png`
- `9.png`

## Notes

- Recommended size: square image (for example, 512x512).
- If a digit PNG is missing, the app automatically falls back to its generated texture.
